# 资讯 App 阅读活动系统（题目 10）

题目 10《资讯 App 阅读活动的发布、奖励、申诉与结算核查》的教学实现。

## 功能范围

- 运营：创建并发布活动、查看发放汇总与异常核查
- 用户：查看活动与每日进度、积分流水、提交申诉
- 模拟阅读服务：发送阅读事件、提供可信阅读记录查询
- 客服：核查申诉、驳回或补入缺失记录（复用统一发奖规则）

## 技术栈

- Go 1.26 + Gin
- MySQL（唯一索引承载幂等约束）
- 简单 HTML 页面（Go html/template）
