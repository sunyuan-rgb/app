# 题目 10 验收条款清单

> 依据原始题面整理；验收时逐条填写结论与证据位置。题面原文优先于本清单。

## A. 八条业务规则

| # | 条款要点 | 结论 | 证据位置 |
| --- | --- | --- | --- |
| R1 | 运营发布后：开始/结束时间、每日门槛、积分数固定；不改规则、不撤销已发积分 | | |
| R2 | 事件须阅读服务鉴权；含全局唯一编号、用户、文章、发生时间；发生时间 ∈ 活动期间且 ≤ 接收时间 | | |
| R3 | 同用户同日同文章只计一次；同编号换内容拒绝；迟到 ≤24h 按发生日期归属，超窗拒绝 | | |
| R4 | 达标 3 篇只发一次 30 分；流水与余额一致；活动结束后窗口内迟到事件仍受理且归发生日 | | |
| R5 | 用户可按日期查进度、提交通；每天 1 条未结申诉；不能看他人数据；客服不能改原始事件或直接编辑余额 | | |
| R6 | 客服结合已接收事件 + 阅读服务可信查询核查；证据不足驳回并说明；补入记录走相同奖励规则且受活动期/窗口约束 | | |
| R7 | 自动入账与申诉处理并发：同用户同活动日只发一次；已获奖申诉告知流水，不重复补发；处理结果/依据/操作者留痕 | | |
| R8 | 窗口关闭后运营核查：各日达标人数、发奖人数、积分总额、申诉结果；不一致项有可追溯明细；不以事件条数当达标 | | |

## B. 五个必演场景（须实际操作 + 持久化结果）

| 场景 | 关键验证点 | 结论 | 证据位置 |
| --- | --- | --- | --- |
| S1 正常活动 | 发布 → 读 3 篇 → 自动发奖 → 查流水 → 运营查汇总 | | |
| S2 重复与延迟 | 重复文章/事件、跨日迟到、活动结束后窗口内事件：归属与奖励正确 | | |
| S3 申诉成立 | 第 3 篇可信记录未送达 → 申诉 → 客服补入 → 奖励到账；原事件重送不重复发 | | |
| S4 申诉不成立 | 不满 3 篇/活动外/超窗 → 驳回说明原因，积分不变 | | |
| S5 并发与收尾 | 自动入账 vs 客服补发并发只发一次；越权被拒；窗口结束后核清奖励/余额/申诉 | | |

## E. 红线（任一违反 → 直接不通过）

- 客服直接修改余额或原始事件数据
- 发奖未与流水/余额同事务
- 重复发奖（并发或补发路径）
- 越权访问未被拒绝
- 密钥/敏感信息进入仓库、日志、视频
- 静态页面/写死结果代替业务实现
