R1业务日按发生时间的北京时间归属（跨日迟到归发生日）
R2迟到 ≤24h 受理；活动期外拒绝；拒绝事件留痕可查
R3同用户同日同文章只计一次（数据库唯一键，非内存判断）
R4同事件编号同内容幂等返回；换内容拒绝并写 event_conflict
R5每日达 3 篇发 30 分，仅一次（reward 唯一键幂等）
R6奖励记录+流水+余额同事务，余额恒等于流水合计
R7客服补入复用统一事件路径，同样受窗口/活动期/去重约束
R8同用户同日仅一条未结申诉；客服无直接改余额/原始事件路径
